MERCARI PULSE · PROJECT OVERVIEW

不错过每一次上新

面向日本 Mercari 的低延迟桌面关键词监控工具。通过关键词监控、收藏跟踪、Windows 通知与 QQ 机器人订阅，把商品发现、筛选和提醒汇集到一个本地桌面应用中。

Electron + React100 ms 起轮询Windows 通知QQ 群 / 私聊本地加密密钥

核心功能

每项功能围绕“尽快发现、准确过滤、按需通知、持续可追踪”设计。

⌕

独立关键词监控

每个关键词独立设置 0.1 / 0.5 / 1 / 2 / 5 / 10 秒间隔、价格区间、屏蔽词、初始展示数量和通知开关。

↻

新商品与旧商品更新

商品 ID 去重后识别真实上新；可选跟踪已存在商品的价格、状态、图片和名称编辑，并标注更新原因。

♥

收藏状态追踪

支持从动态或链接/ID 添加收藏；定期检查降价、涨价、售出状态和详情变化，售出后停止重复检查。

▣

商品动态管理

按关键词分类浏览，区分直售、拍卖、已售和离线期间上新；每关键词保留 200 条、全部视图保留 300 条。

Q

QQ 精准订阅

支持多个机器人、普通群与私聊。用户绑定后拥有独立关键词和屏蔽词，只接收自己订阅的商品。

◆

本地安全运行

AppSecret 使用 Windows DPAPI 保存；渲染层隔离 Node.js，外部商品链接须验证后才会打开。

发现与提醒流程

首次添加只建立基线，后续才把新增结果作为上新通知；离线期间结果只补到动态，避免启动时打扰。

1. 关键词调度按各任务独立间隔发送搜索请求。
2. 结果过滤价格、屏蔽词、图片可用性与商品类型校验。
3. 基线与去重通过商品 ID 与已观察快照判断新商品或编辑。
4. 本地记录写入商品动态、收藏状态和运行日志。
5. 按需投递Windows 通知、QQ 文本及后台图片补发。

QQ 机器人指令

在私聊中直接发送，或在群聊中 @ 机器人后发送。未绑定时必须先绑定名称。

  • /bind 名称：绑定或修改当前私聊/群聊的显示名称。
  • /add 关键词：订阅关键词；可追加 exclude 屏蔽词。
  • /remove 关键词：移除当前会话订阅的关键词。
  • /list / /clear confirm / /help：查看、确认清空和获取帮助。
延迟说明：轮询间隔是应用发起相邻检查的目标时间，实际可见时间仍取决于 Mercari 搜索索引刷新、网络 RTT 和服务端限流。出现 401 / 403 / 429 或网络异常时，应用会自动退避并在冷却后恢复。
