## Why

煤炉目前只在运行电脑上显示桌面通知，并可向 QQ 目标推送商品上新。用户离开电脑后，无法通过苹果系统通知及时接收商品上新、旧商品更新以及收藏商品的降价或售出变化。需要增加独立的 Bark 手机推送通道，并支持同时向多台 iPhone 广播。

## What Changes

- 新增独立的 Bark 手机推送设置，默认关闭，不受现有桌面通知开关影响。
- 支持一个全局 Bark Server 和多个 Bark 设备；所有已启用设备接收相同消息。
- 支持官方 Bark Server 默认地址和自建 HTTP/HTTPS 地址，并对明文 HTTP 显示安全警告。
- 使用 Windows DPAPI 加密保存各设备的 `deviceKey`，渲染进程只能获知密钥是否已配置。
- 对商品上新、旧商品更新及收藏商品降价/售出变化发送 Bark 通知，固定包含名称、价格、变化摘要和商品链接，可独立控制商品图片。
- 提供普通和时效性两个全局通知等级；声音继续由各 iPhone 的 Bark/iOS 设置管理。
- 每台 Bark 设备独立发送；网络错误、超时或 HTTP 5xx 在两秒后最多重试一次，HTTP 4xx 不重试，单台失败不影响其他设备。
- 提供设备级测试通知、最小配置校验以及不泄露 `deviceKey` 的诊断日志。

## Capabilities

### New Capabilities

- `bark-mobile-notifications`: 定义 Bark Server、多个 Bark 设备、安全存储、通知内容、广播、重试、测试及设置界面行为。

### Modified Capabilities

无。

## Impact

- 影响主进程的监控事件分发、IPC 注册、网络请求和诊断日志。
- 影响共享设置类型、持久化状态默认值与旧状态兼容加载。
- 影响预加载桥接接口和偏好设置界面。
- 扩展本地加密密钥存储以管理 Bark 设备密钥的保存、读取和删除。
- 新增 Bark 通知模块及相应单元测试、配置测试和回归验证。
- 不修改 Mercari 查询、基线、去重、商品动态或 QQ 订阅语义。
