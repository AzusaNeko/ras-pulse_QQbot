# Ras Pulse

Ras Pulse 是一个面向日本二手交易平台的低延迟桌面关键词动态提醒工具。它在独立的 Electron 主进程中持续检查最新商品，检测到建立基线后出现的新商品时，通过桌面通知、应用内列表、Bark 手机推送和 QQ 机器人提醒用户。

详细版本记录见 [CHANGELOG.md](CHANGELOG.md)。

可直接在浏览器离线打开的项目功能介绍位于 [docs/project-overview.html](docs/project-overview.html)。

## 功能

- 多关键词并行监控，支持每个关键词独立设置 0.1 秒极速、0.5 秒快速、1/2/5/10 秒轮询；两种高速模式均可在偏好设置中配置允许的并发任务数量
- 排除关键词、最低价和最高价过滤
- 首次检查可选择展示按时间排序的 1～5 条商品，同时建立基线且不误报
- 商品 ID 持久化去重，重启后不会重复通知；商品动态每个关键词最多保留 200 条、全部最多 300 条，触发总量回收时优先保留每个关键词的最后一条
- 商品动态按关键词分类筛选；缩略图加载失败的商品卡片自动隐藏
- 商品缩略图无法访问、缺失或请求超时的条目会暂不写入动态或推送，并在后续轮询自动重试，避免临时 CDN 超时导致永久漏报
- 商品动态支持二次确认后单条删除；取消监控时可选择是否清理关联动态
- 商品可收藏；侧边栏“我的收藏”集中管理收藏项，每 30 秒检查在售/已售状态和价格变化，并发送桌面提醒
- 网络错误指数退避，恢复后自动回到设定间隔
- 监听状态的定时器健康检查：任务超过 15 秒未检查会自动重建定时器，不影响限流退避策略
- Windows 系统通知、声音开关和托盘常驻
- 后台通知实例保活、失败时托盘气泡降级，并提供一键测试通知
- 可分别控制通知是否包含商品缩略图、商品名称和价格；开启图片时使用右下角桌面通知卡片展示大图
- QQ 官方机器人推送：支持多个普通 QQ 群和 QQ 私聊目标；商品文字提醒优先到达，图片随后以纯内存上传方式补发，包含名称、价格和链接
- Bark 手机推送：支持一个官方或自建 Server、多台 iPhone 广播、普通/时效性通知、商品图片、点击跳转和逐设备测试
- Electron 安全隔离：渲染层无 Node.js 权限，外链仅限已验证的商品站点

## 功能工作方式

### 商品监控与动态

- 每个关键词均有独立的调度器、轮询间隔、屏蔽词、价格范围、旧商品更新开关与 Windows 弹窗开关。
- 新增关键词先进行“初始同步”：仅将搜索结果中按 Mercari“新しい順”返回的前 1～5 条加入商品动态，作为去重基线，不将其误报为上新。
- 之后每次请求均按照商品 ID 与已观察的商品快照比较。新 ID 记录为“上新”；同一 ID 的价格、状态、主图或名称变化可记录为“旧商品更新”。
- 应用离线期间的搜索结果会标记为“离线期间上新”，仅补入动态，不弹出 Windows 通知，也不推送到 QQ。
- 商品动态的“全部”视图最多显示 300 条；每个关键词自己的动态最多保留 200 条，两套保留策略相互独立。

### 收藏与状态跟踪

- 动态卡片可一键收藏，也可在“我的收藏”中粘贴 Mercari 商品链接或商品 ID 后验证并收藏。
- 收藏项每 30 秒检查一次：已售、降价、涨价、价格恢复以及详情变化均会记录并通知；确认已售后停止后续重复检查。
- 卡片会区分普通直售、拍卖和已售商品；拍卖/已售状态使用不同的视觉边框，方便快速浏览。

### QQ 机器人订阅

- 支持多个 QQ 机器人账号，每个账号可配置多个普通 QQ 群或 QQ 私聊目标。
- 群聊/私聊必须先用 `/bind 名称` 完成绑定；绑定后，关键词和屏蔽词均按当前会话隔离保存。
- 可用 `/add`、`/remove`、`/list`、`/clear`、`/help` 管理订阅。商品推送先发送文字（名称、价格、链接、拍卖/旧商品更新说明），图片在后台下载并补发，不阻塞上新提醒。
- 管理员删除本地关键词时，使用该关键词的已绑定 QQ 目标会同步移除订阅并收到说明消息。

### Bark 手机推送

- Bark 与 Windows 通知、QQ 推送分别启停；开启后，所有启用设备接收相同的上新、旧商品更新和收藏变化。
- 每台 iPhone 使用独立的 Bark `deviceKey`，可分别命名、启停和测试；Key 由 Windows DPAPI 加密保存在普通设置之外。
- 默认使用 `https://api.day.app`，也可填写一个自建 Bark Server。HTTP 地址可以使用，但设置页会提示 Key 与通知正文以明文传输。
- 网络错误、超时或 Server 5xx 会在两秒后重试一次；单台设备失败不会影响其他设备、桌面通知、QQ 推送或监控轮询。

## 架构与数据流

1. React 界面通过 `preload` 暴露的最小 IPC API 发起操作，不直接访问 Node.js、磁盘或网络。
2. Electron 主进程将操作委派给 `MonitorEngine`：它维护关键词定时器、基线、去重状态、回收策略、收藏检查和运行日志。
3. `MercariClient` 负责搜索、详情、Mercari Shops 与图片可用性检测；网络请求有超时与访问受限后的退避冷却。
4. 发现到商品后，主进程更新本地持久化状态、刷新界面、按设置发送 Windows 通知，由 `BarkNotifier` 广播到启用的 Bark 设备，并由 `QQBotNotifier` 分发到匹配的 QQ 订阅目标。
5. `StateStore` 保存非敏感业务数据；QQ AppSecret 和 Bark `deviceKey` 由 `SecretStore` 使用 Windows DPAPI 分文件加密保存。

## 安全边界

- Electron 窗口启用了上下文隔离，渲染层不拥有 Node.js 权限；所有系统能力均经过主进程 IPC 白名单。
- QQ AppSecret 和 Bark `deviceKey` 不返回给界面、不记录到运行日志，也不进入 Git 仓库。
- 外部链接仅允许经验证的 Mercari 商品地址后交由系统浏览器打开。
- 监控功能不尝试绕过验证码、访问控制或服务端限流；检测到 401、403、429 或异常访问时会退避并在冷却后恢复。


## 延迟说明

“1 秒”指应用侧相邻检查的目标间隔。实际发现延迟还会受到商品搜索索引刷新、网络往返时间和服务端限流影响，无法保证商品发布后严格 1 秒内可见。每个任务不会发起重叠请求；失败后会按 2、4、8 秒等节奏自动退避，最长 60 秒。

## QQ 机器人配置

在“偏好设置 → QQ 机器人推送”中填写 QQ 开放平台的 AppID 与 AppSecret。保存并开启后，应用会建立 QQ WebSocket 服务；在目标群内 @ 机器人或私聊机器人一次，软件会自动发现并添加对应推送目标。普通 QQ 群使用 `group_openid`，QQ 私聊使用 `openid`；两者都不是 QQ 号或群号。

AppSecret 仅保存在本机，并使用 Windows DPAPI 加密；不会显示在界面、写入日志或提交到 Git 仓库。请先点击“发送 QQ 测试消息”验证配置。QQ 平台可能对主动消息设置频率或会话限制，请以平台实际返回结果为准。

用户可直接私聊机器人，或在群内 @ 机器人后发送指令：`/bind 名称`、`/add 相机`、`/remove 相机`、`/list`、`/clear confirm`、`/help`。如需排除容易混淆的结果，可发送 `/add バンドリ exclude バンドリエール、バンドリング、バンドリーノ`；屏蔽词按商品名称匹配，且只作用于当前私聊或当前群聊，不影响其他用户。每个私聊用户与每个群聊拥有各自独立的关键词列表，只会收到自己订阅关键词的商品；移除关键词后将立即停止对应推送。

在 QQ 机器人设置中点击“同步 QQ 指令面板”，会为私聊和群聊创建指令面板，不再创建私聊自定义菜单。面板会预填 `/add `，用户补充关键词后再手动发送，例如 `/add bangdream`；屏蔽词格式为 `/add バンドリ exclude バンドリエール、バンドリング`。发送 `/clear` 会先提示确认，只有发送 `/clear confirm` 才会清除当前私聊或群聊的所有订阅。QQ 客户端通常通过输入 `/` 唤起指令面板。

## Bark 手机推送配置

1. 在每台 iPhone 安装 Bark，打开 App 并复制该设备推送地址中的 `deviceKey`。
2. 打开“偏好设置 → Bark 手机推送”，保留默认 Server 或填写自建 Server。
3. 添加设备，填写可选名称和 `deviceKey`，保存后逐台点击“测试”。
4. 根据需要选择普通或时效性通知、是否显示商品图片，最后开启 Bark 总开关。

所有启用设备接收相同内容。煤炉始终发送商品名称、价格、变化摘要和商品链接；声音由每台 iPhone 的 Bark App 与 iOS 通知设置管理。使用 `http://` 自建 Server 时，Key 与通知内容可能被局域网中的其他设备读取，建议在非完全可信网络中使用 HTTPS。

## 接口与合规

目标日本二手交易平台没有为普通用户提供稳定的公开搜索 API。本项目使用网站当前采用的搜索请求格式和 DPoP 签名，因此站点改版后可能需要更新适配器。请仅用于个人、低频监控，遵守目标平台的服务条款和当地法律；不要绕过验证码、访问控制或限流。若出现 401、403 或 429，请降低频率并停止批量请求。
