# Mercari Pulse

Mercari Pulse 是一个面向 Mercari JP（煤炉）的低延迟桌面关键词监控器。它在独立的 Electron 主进程中持续检查最新商品，检测到建立基线后出现的新商品时，通过桌面通知和应用内列表提醒用户。

## 功能

- 多关键词并行监控，默认检查间隔 1 秒
- 排除关键词、最低价和最高价过滤
- 首次检查可选择展示按时间排序的 1～5 条商品，同时建立基线且不误报
- 商品 ID 持久化去重，重启后不会重复通知
- 商品动态支持二次确认后单条删除；取消监控时可选择是否清理关联动态
- 网络错误指数退避，恢复后自动回到设定间隔
- Windows 系统通知、声音开关和托盘常驻
- 后台通知实例保活、失败时托盘气泡降级，并提供一键测试通知
- 可分别控制通知是否包含商品缩略图、商品名称和价格；开启图片时使用右下角桌面通知卡片展示大图
- Electron 安全隔离：渲染层无 Node.js 权限，外链只允许 Mercari 域名

## 开发与构建

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

检查与生产构建：

```powershell
npm test
npm run build
npm run dist
```

`npm run dist` 会在 `release` 目录生成 Windows NSIS 安装程序。

## 延迟说明

“1 秒”指应用侧相邻检查的目标间隔。实际发现延迟还会受到 Mercari 搜索索引刷新、网络往返时间和服务端限流影响，无法保证商品发布后严格 1 秒内可见。每个任务不会发起重叠请求；失败后会按 2、4、8 秒等节奏自动退避，最长 60 秒。

## 接口与合规

Mercari 没有为普通用户提供稳定的公开搜索 API。本项目使用网站当前采用的搜索请求格式和 DPoP 签名，因此 Mercari 改版后可能需要更新适配器。请仅用于个人、低频监控，遵守 Mercari 的服务条款和当地法律；不要绕过验证码、访问控制或限流。若出现 401、403 或 429，请降低频率并停止批量请求。

## 项目结构

```text
src/main/       Electron 主进程、监控调度、Mercari 适配器、持久化
src/preload/    安全 IPC 桥
src/renderer/   React 用户界面
src/shared/     跨进程类型定义
```
