# Ras Pulse

Ras Pulse 是一个面向日本二手交易平台的低延迟桌面关键词动态提醒工具。它在独立的 Electron 主进程中持续检查最新商品，检测到建立基线后出现的新商品时，通过桌面通知、应用内列表和 QQ 机器人提醒用户。

## 功能

- 多关键词并行监控，支持每个关键词独立设置 0.5 秒极速、1/2/5/10 秒轮询；极速模式同一时间仅允许一个关键词使用
- 排除关键词、最低价和最高价过滤
- 首次检查可选择展示按时间排序的 1～5 条商品，同时建立基线且不误报
- 商品 ID 持久化去重，重启后不会重复通知；商品动态每个关键词最多保留 200 条、全部最多 300 条，触发总量回收时优先保留每个关键词的最后一条
- 商品动态按关键词分类筛选；缩略图加载失败的商品卡片自动隐藏
- 商品缩略图无法访问、缺失或请求超时的条目会被直接忽略，不写入动态也不推送
- 商品动态支持二次确认后单条删除；取消监控时可选择是否清理关联动态
- 商品可收藏；侧边栏“我的收藏”集中管理收藏项，每 30 秒检查在售/已售状态和价格变化，并发送桌面提醒
- 网络错误指数退避，恢复后自动回到设定间隔
- 监听状态的定时器健康检查：任务超过 15 秒未检查会自动重建定时器，不影响限流退避策略
- Windows 系统通知、声音开关和托盘常驻
- 后台通知实例保活、失败时托盘气泡降级，并提供一键测试通知
- 可分别控制通知是否包含商品缩略图、商品名称和价格；开启图片时使用右下角桌面通知卡片展示大图
- QQ 官方机器人推送：支持多个普通 QQ 群和 QQ 私聊目标；商品文字提醒优先到达，图片随后以纯内存上传方式补发，包含名称、价格和链接
- Electron 安全隔离：渲染层无 Node.js 权限，外链仅限已验证的商品站点
- 离线授权：每份授权码使用 Ed25519 签名并绑定单台设备；未激活时不启动商品监控

## 开发与构建

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

检查与生产构建：

```powershell
npm test
npm run build
npm run dist
```

`npm run dist` 会在 `release` 目录生成 Windows NSIS 安装程序。

## 延迟说明

“1 秒”指应用侧相邻检查的目标间隔。实际发现延迟还会受到商品搜索索引刷新、网络往返时间和服务端限流影响，无法保证商品发布后严格 1 秒内可见。每个任务不会发起重叠请求；失败后会按 2、4、8 秒等节奏自动退避，最长 60 秒。

## QQ 机器人配置

在“偏好设置 → QQ 机器人推送”中填写 QQ 开放平台的 AppID 与 AppSecret。保存并开启后，应用会建立 QQ WebSocket 服务；在目标群内 @ 机器人或私聊机器人一次，软件会自动发现并添加对应推送目标。普通 QQ 群使用 `group_openid`，QQ 私聊使用 `openid`；两者都不是 QQ 号或群号。

AppSecret 仅保存在本机，并使用 Windows DPAPI 加密；不会显示在界面、写入日志或提交到 Git 仓库。请先点击“发送 QQ 测试消息”验证配置。QQ 平台可能对主动消息设置频率或会话限制，请以平台实际返回结果为准。

用户可直接私聊机器人，或在群内 @ 机器人后发送指令：`添加关键词 相机`、`移除关键词 相机`、`关键词列表`。如需排除容易混淆的结果，可发送 `添加关键词 バンドリ 屏蔽 バンドリエール、バンドリング、バンドリーノ`；屏蔽词按商品名称匹配，且只作用于当前私聊或当前群聊，不影响其他用户。每个私聊用户与每个群聊拥有各自独立的关键词列表，只会收到自己订阅关键词的商品；移除关键词后将立即停止对应推送。

在 QQ 机器人设置中点击“同步 QQ 菜单与指令”，会为私聊创建“监控管理”自定义菜单，并为私聊和群聊创建全局指令面板。菜单或面板会预填 `/添加关键词 `，用户补充关键词后再手动发送，例如 `/添加关键词 bangdream`；屏蔽词格式为 `/添加关键词 バンドリ 屏蔽 バンドリエール、バンドリング`。发送 `/清除所有关键词` 会先提示确认，只有发送 `/清除所有关键词 确认` 才会清除当前私聊或群聊的所有订阅。QQ 客户端通常通过输入 `/` 唤起指令面板。

## 离线授权（仅发行者）

首次配置时执行一次：

```powershell
node scripts/generate-license-keypair.mjs
```

该命令会在 `license-admin/issuer-private.pem` 创建发行私钥，并在控制台输出公钥。私钥已被 `.gitignore` 排除：请离线备份，绝不要发给用户、上传 GitHub 或打包进安装程序。

用户打开未激活的软件后会看到“设备代码”。使用该代码签发仅限该设备的授权码：

```powershell
node scripts/issue-license.mjs --private license-admin/issuer-private.pem --holder 用户名 --device 用户的设备代码 --expires 2027-12-31
```

将输出的 `MP1.…` 授权码发送给用户。省略 `--expires` 即签发不设到期日的授权。离线授权不能远程撤销已发出的授权码；如需撤销、设备数量限制或在线续期，应升级为在线授权服务。

## 接口与合规

目标日本二手交易平台没有为普通用户提供稳定的公开搜索 API。本项目使用网站当前采用的搜索请求格式和 DPoP 签名，因此站点改版后可能需要更新适配器。请仅用于个人、低频监控，遵守目标平台的服务条款和当地法律；不要绕过验证码、访问控制或限流。若出现 401、403 或 429，请降低频率并停止批量请求。

src/shared/     跨进程类型定义
